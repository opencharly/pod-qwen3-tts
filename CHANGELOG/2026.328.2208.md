# 2026.328.2208 — docs(skill): the model cache is ONE shared store in the XDG data root

## Summary

Document the shared model cache the deployment uses, and the XDG contract it follows: the
checkpoint is Hugging Face **cache** data under the charly **data** root the resolver owns
(`spec/storeroot`, DESIGN D-STORE-1 / D-STORE-11 / D-STORE-12) — `<data root>/models/huggingface`,
which is `~/.local/share/charly/models/huggingface` with the default XDG roots.

Binding the candy's `models` volume there in every pod and bed downloads the checkpoint **once**,
and every qwen3-tts pod reads it. The shim and the on-demand worker inherit `HF_HOME`, so both read
**and download** into the same store. The default per-image named volume duplicates the checkpoint
per pod and must not be used for this cache.
